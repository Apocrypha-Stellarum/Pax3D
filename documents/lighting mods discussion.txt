│ Context                                                                                                  │
│                                                                                                          │
│ Pax3D (our Panda3D fork) now has a pax3d_simplepbr package with a full Kawase bloom chain and ACES       │
│ tonemapping. The game currently uses graphics/pax_pbr/ — a custom PBR pipeline wrapper with custom sun   │
│ uniforms (u_sun_dir_world/u_sun_color) bypassing Panda3D's DirectionalLight system. There is no          │

│ We cannot simply swap to pax3d_simplepbr as the HOW_TO_USE doc suggests, because that would use          │

│ Approach: Port the bloom chain and ACES tonemap from pax3d_simplepbr into our existing graphics/pax_pbr/ │
