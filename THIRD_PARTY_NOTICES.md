panda3d-simplepbr
-----------------

The rendering pipeline in `pax3d_render/` started from **panda3d-simplepbr**
by Mitchell Stokes, and its physically-based and shadow shaders still carry
that code.

- Project: <https://github.com/Moguri/panda3d-simplepbr>
- Version this work descends from: 0.13.1
- License: BSD 3-Clause

### Files containing derived code

| File | Relationship |
|---|---|
| `pax3d_render/shaders/pax_pbr.frag` | Derived from `simplepbr.frag`. The BRDF core is carried substantially unchanged: Schlick Fresnel with the spherical Gaussian approximation, Smith GGX visibility, GGX/Trowbridge-Reitz microfacet distribution, Lambert diffuse, spherical-harmonic irradiance, the light loop, and the split-sum IBL block. |
| `pax3d_render/shaders/pax_pbr.vert` | Derived from `simplepbr.vert`. Vertex transform, view and world TBN construction, and the shadow-position varying loop are carried substantially unchanged. |
| `pax3d_render/shaders/shadow.vert` | Derived from `shadow.vert`. |
| `pax3d_render/shaders/shadow.frag` | Derived from `shadow.frag`. |
| `pax3d_render/shaders/post.vert` | Derived from `post.vert`. |
| `pax3d_render/shaders/tonemap.frag` | Largely rewritten. What remains from `tonemap.frag` is the SDR LUT sampling block and the Hejl-Dawson operator, which is retained as one of four operators and is no longer the default. See the note below. |
| `pax3d_render/shaderutils.py` | Derived from `_shaderutils.py`. Shader loading, `#define` injection, and compilation. |
| `pax3d_render/pipeline.py` | No source lines carried, but the pipeline structure descends from simplepbr's `Pipeline` class, including the shader-recompile, tonemap-setup, environment-uniform, shadow-caster and per-frame update stages. |
| `pax3d_simplepbr/` | An earlier, now retired fork kept for reference. Substantially unmodified simplepbr. |

### Modifications

Pax3D has changed this code. The significant changes are:

- Ported to native GLSL 330 core. The original GLSL 120 sources and the
  runtime 120-to-330 transform were removed.
- A world-space directional sun path with its own uniforms, alongside the
  original `p3d_LightSource` path.
- Shadow work: texel snapping, world-space normal bias, per-node casting
  control, and a configurable bone palette shared with the depth pass.
- Shader variants added for atmospheric scattering, terrain splatting,
  hex tiling, height blending, a waterline, glass, double-sided lighting,
  per-node ambient and environment binding, GPU morph targets, instancing,
  cutout alpha, detail maps, and spot exponent.
- The tonemap stage was rebuilt. simplepbr applies one hard-coded filmic
  curve. Pax3D offers ACES, Reinhard, Uncharted 2 and Hejl-Dawson, selectable
  at runtime, and defaults to ACES. The stage also composites bloom, SSAO and
  lens flare, and dithers the result to break 8-bit banding.
- The BRDF lookup texture is generated by `tools/gen_brdf_lut.py` and is
  not the one shipped with simplepbr.

Khronos glTF-Sample-Viewer
--------------------------

panda3d-simplepbr states that its PBR shader is heavily inspired by the
**Khronos glTF Sample Viewer**, and carries that note in the source. Pax3D
inherits the lineage through simplepbr and preserves the attribution here.

- Project: <https://github.com/KhronosGroup/glTF-Sample-Viewer>
- License: Apache License 2.0, January 2004
  (<https://www.apache.org/licenses/LICENSE-2.0>)

The relationship is indirect. No file in this repository was copied from
the Sample Viewer. It is credited because the physically-based shading
model in `pax3d_render/shaders/pax_pbr.frag` traces back to it, and because
the reference implementation is worth pointing people at.

Other credited work
-------------------

These are techniques and formulas used under their published terms or
implemented from public descriptions. They are listed for completeness and
credited in the source where they appear.

- Hejl-Dawson filmic tonemap curve, by Jim Hejl and Richard Burgess-Dawson.
  This is a published curve. It reached Pax3D through simplepbr, which used
  it as its tonemap. Pax3D keeps it as a selectable operator so older content
  tuned against it still renders as intended.
- Interleaved gradient noise, by Jorge Jimenez (2014).
- Stochastic hex tiling, after Morten Mikkelsen.
- Uncharted 2 filmic tonemap curve, by John Hable.
- ACES tonemap approximation, after Stephen Hill.
